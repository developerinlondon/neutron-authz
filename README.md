# Moved: this library is now [agentauthz](https://github.com/developerinlondon/agentauthz)

`neutron-authz` was renamed to **agentauthz** in August 2026 — the engine was built
ground-up for agent authorization, and the name now says so.

- Repository: <https://github.com/developerinlondon/agentauthz>
- Docs: <https://developerinlondon.github.io/agentauthz/>
- npm: [`agentauthz`](https://www.npmjs.com/package/agentauthz) (the old
  `@neutroncore/authz` package is deprecated and frozen at 0.4.2)

This stub exists only to redirect the old GitHub Pages docs URLs.
